# Option Hub screenshot gallery

Every page of Option Hub by Mr. Chartist in dark and light mode, plus phone views and feature close-ups: **88 images**, 6.5 MB of WebP.

All captures were taken in **sample-data mode** (`VITE_DATA_MODE=sample`, no proxy, no broker keys), which is what you see on first run. Numbers are generated for illustration and are never real prices. Desktop images are 1600 × 1000; phone images are 390 × 844 at 2× (780 × 1688).

A machine-readable list with titles, routes, themes, sizes and descriptions is in [`manifest.json`](manifest.json), for reuse on [mrchartist.com](https://mrchartist.com) and elsewhere. Back to the [main README](../../README.md).
